# Markdown记录模板

以下为按需复制的结构，方括号字段需要用真实观察替换；不得把模板复制到真实档案后当成已发生记录。没有证据写未评估/未运行/待确认。保留每份档案现有历史。

同一套字段供两平台使用：Codex写绑定工作区Markdown；ChatGPT写可见会话记录和报告快照，不声称改本地文件。结束或切平台汇总，不要求学生逐条手工填表。新外部发现无本地ID时用EXT-报告ID-序号，保留来源；既有回答被引用不产生新成绩。

## 当前题目状态（progress.md当前状态区）

```markdown
- 会话ID：[S-日期-序号]
- 当前模式：[今日训练/初始测评/编程挑战/面试/补弱/项目]
- 环节：[昨日复习/编程/计算机基础/压力追问/项目问答/评价与计划]
- 状态：等待回答
- 题目ID：[Q-日期-序号]
- 题目原文：[完整题干，不包含标准答案]
- 提示等级：0
- 完整答案展示：否
- 外部AI使用：待确认
- 关联薄弱点/复测槽位：[无或ID及next_session/day3/day7]
- 下一步：[等待学生分析/代码；仅一个待回答主要问题]
```

## 回答尝试（progress.md追加）

```markdown
### [attempt_id]｜[实际日期]｜[知识点]

- 事件ID：[event_id]；会话：[session_id]；题目：[question_id]
- 学生回答/代码：[原话短摘录或路径，必要时附完整题目引用]
- 观察与评估范围：[具体行为]
- 结果：[正确/部分正确/错误/无法评估]
- 提示等级：[0–3]；完整答案展示：[否/是及时间]
- 外部AI使用：[学生确认无/学生自报有及帮助/待确认]
- 独立性：[独立/AI辅助/答案已揭示/未知]；核验范围：[对话观察+学生自报等]
- 测试：[路径、执行方式、实际输出摘要；未运行则原因]
- 证据来源：[Codex观察/本地执行/学生自报/ChatGPT外部待核验]
- 关联薄弱点：[W-ID或无]；反馈与下一步：[一个任务]
```

## 薄弱点（weaknesses.md追加详情，索引同步）

```markdown
### [weakness_id]｜[具体知识点]

- 首次证据日期/锚点：[D]；最近观察：[日期]
- 状态：待验证；严重程度：[轻/中/重及当前影响]；置信度：[低/中/高及依据]
- 证据：[attempt_id、学生片段/代码、观察、来源]
- 训练方法：[一项可执行练习]
- 独立解释证据：未取得
- 独立应用证据：未取得
- next_session：下一次训练；状态：待下次训练；结果：未进行
- day3：[D+3]；状态：待复测；结果：未进行
- day7：[D+7]；状态：待复测；结果：未进行
- 历史变化：[event_id、实际日期、原值→新值、证据与理由]
```

## 面试记录（interviews.md追加）

```markdown
### [session_id]｜[实际日期]｜[面试方向]

- 状态：[进行中/已结束/部分完成/暂停]
- 题目与回答：[question_id、attempt_id、原话片段与针对性追问]
- 帮助与独立性：[提示等级、是否提前看答案、外部AI自报]
- 评分：[仅已观察维度0–4或未评估，每项列证据ID和理由]
- 错误分析：[具体错误与当前影响，不扩大范围]
- 改进任务：[一项优先动作]
- 复测：[weakness_id、槽位、计划日期]
- 未完成/恢复位置：[题干、提示、下一步]
```

## 计划/周总结事件（对应档案追加）

```markdown
### [event_id]｜[实际日期]｜[计划调整/日终/周总结]

- 覆盖区间及真实训练：[实际天数、已完成/未完成环节]
- 证据：[attempt_id/session_id、独立与辅助次数、复测实际结果]
- 能力变化：[可比证据；无则暂无法判断]
- 原计划→新计划：[内容]
- 调整理由：[具体证据与用户约束]
- 下一次重点：[一项专项与成功标准]
```
